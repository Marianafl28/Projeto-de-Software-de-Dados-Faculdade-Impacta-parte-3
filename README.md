# 📊 Projeto de Análise de Vendas de Soja

Este projeto apresenta um conjunto de dados simulados de vendas de soja, com o objetivo de realizar análises e gerar insights sobre o mercado.

---

## 📁 Estrutura do Projeto

* `dados_vendas.csv` → Base de dados principal utilizada nas análises
* `Vendas e vendedores.xlsx` → Arquivo original em Excel
* `imagem do BI.png` → Visualização do dashboard (Power BI)
* `README.md` → Documentação do projeto

---

## 📌 Sobre os Dados

A base contém informações sobre vendas realizadas em diferentes regiões do Brasil, incluindo:

* Compradores
* Empresas
* Vendedores
* Localização
* Segmento de mercado
* Quantidade vendida

---

## 📊 Dicionário de Dados

| Coluna               | Descrição                                     |
| -------------------- | --------------------------------------------- |
| ID                   | Identificador único da venda                  |
| Comprador            | Nome do cliente                               |
| Empresa              | Empresa compradora                            |
| Vendedor             | Responsável pela venda                        |
| Cidade               | Cidade onde ocorreu a venda                   |
| Diretoria            | Região do país                                |
| Segmento             | Tipo de mercado (ex: Varejo, Alimentos, etc.) |
| Quantidade_Toneladas | Volume vendido em toneladas                   |

---

## 🔎 Objetivo da Análise

O projeto tem como objetivo:

* Analisar o volume de vendas por região
* Identificar os vendedores com melhor desempenho
* Comparar segmentos de mercado
* Explorar padrões de consumo
